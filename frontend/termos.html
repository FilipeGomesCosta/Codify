Termos de Uso

O Codify é uma plataforma de ensino de programação criada para fins educacionais. Ao criar uma conta você se compromete a usar o site de forma respeitosa e a não compartilhar sua senha.

Política de Privacidade

Guardamos apenas os dados necessários para o funcionamento do site: nome, e-mail, senha (criptografada), progresso nas missões e arquivos enviados. Esses dados não são compartilhados com terceiros.
